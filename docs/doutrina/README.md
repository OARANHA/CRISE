# Doutrina operacional — Sistema Vivo VIGIAFAST

Este **manual enxuto** explica os princípios e os limites de ação para trabalho humano ou assistido por IA. O nome "Sistema Vivo" descreve um método de atualização verificável; **não é um subsistema implantado, nem aprova mudanças futuras automaticamente**.

- [02 — Fronteiras de autoridade](02-fronteiras-de-autoridade.md)

**Hierarquia:** [PROJECT_SOURCE](../PROJECT_SOURCE.md) → [AGENTS](../../AGENTS.md) → evidências de Git/código/CI → ADRs aceitas para arquitetura → [estado canônico](../CANONICAL_STATE.md) → orientações complementares da doutrina e skills. Se houver conflito, parar, apontar a diferença e reconciliar; **não deixar a doutrina contradizer uma decisão aceita**.

O manual foi inspirado no padrão organizacional mostrado como referência, mas tem redação e escopo próprios do VIGIAFAST.
